# Trainer Copilot — Data Contract (v1.0.0)

The Trainer Copilot is built independently of this platform. This contract is
the platform's only lever over its behavior: the copilot consumes these
read-only, provenance-carrying endpoints and must never author drill content.

## Endpoints (static JSON, versioned with the content pack)

| Path | Contents |
|---|---|
| `/contract/v1/manifest.json` | Contract version, grounding rule, per-drill completeness flags, endpoint index. Generated by `scripts/export_contract.py`. |
| `/content/chapter2_section1.json` | Canonical content: glossary, roster, per-drill tables (structure of command, word of command, stages + faults + figure refs, layout/ratio, MOI sequence), all cells verbatim with per-cell status and provenance. Generated by `scripts/ingest_chapter2.py` — deterministic extraction, no LLM in the path. |
| `/content/videos.json` | Companion-video registry: file, drill linkage, approval status, verbatim transcriptions of on-screen text. |
| `/contract/v1/generation-boundary.json` | Machine-readable classification of copilot job types: pure-retrieval (safe), composition-adjacent (mandatory human review), forbidden (must not be built). |

## Grounding rules (mandatory for any integrator)

1. **Cite or refuse.** Every answer cites the provenance of the field it came
   from (`table_caption` + `doc_version`). If the field's status is
   `pending`/`placeholder_pending`/`empty`, the only valid answer is:
   *"Not yet authorized in the source manual."*
2. **Verbatim for graded content.** Commands, syllable splits, tones, timing
   trigger points, cadence call-outs, and fault wording are graded content —
   they are returned exactly as stored, never paraphrased.
3. **No extrapolation.** Squad sizes outside the manual's documented bands,
   drills without tables, unanswered questions — all get flagged as
   undocumented, never bridged with general knowledge.
4. **Respect the generation boundary.** Jobs listed as `forbidden` in
   `generation-boundary.json` must not be implemented against this contract.
   `composition_adjacent` jobs require human review before their output is
   used, and their outputs must tag every line as manual-sourced vs composed.
5. **Version pinning.** Answers cache against `doc_version` +
   `contract_version`; a change in either invalidates cached answers.

## Job catalog

See `generation-boundary.json` for the authoritative machine-readable list.
Summary: Q&A with citations, glossary lookup, command breakdown, fault-checklist
assembly, layout/ratio lookup, and coverage reporting are safe pure-retrieval
jobs. Lesson-plan adaptation and templated (counts-only) debriefs are
composition-adjacent. Authoring technique cues, generating quiz items,
gap-filling from general knowledge, and media generation are forbidden.

## Regenerating

```
python3 scripts/ingest_chapter2.py <chapter2.docx> --out app/public
python3 scripts/export_contract.py
```

Both scripts are deterministic; diffs in their output correspond 1:1 to diffs
in the source material.
